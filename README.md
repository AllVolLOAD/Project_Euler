# Project Euler - Решения задач

Этот репозиторий содержит мои решения задач с [Project Euler](https://projecteuler.net/) на языке Python.

## 📋 Описание

Project Euler — это серия сложных математических и вычислительных задач, требующих для решения больше, чем просто математические инсайты. Каждая задача решена с использованием Python.

## 📁 Структура репозитория

Каждая задача находится в отдельной папке с описанием на русском языке:

- **1. Числа, кратные 3 или 5** - Сумма всех чисел меньше 1000, кратных 3 или 5
- **2. Четные числа Фибоначчи** - Сумма всех четных элементов ряда Фибоначчи до 4 миллионов
- **3. Наибольший простой делитель** - Нахождение наибольшего простого делителя числа
- **4. Наибольшее произведение-палиндром** - Поиск наибольшего палиндрома-произведения
- **5. Наименьшее кратное** - Наименьшее число, делящееся на все числа от 1 до N
- **6. Разность между суммой квадратов и квадратом суммы**
- **7. 10001-е простое число**
- **8. Наибольшее произведение в последовательности**
- **9. Особая тройка Пифагора**
- **10. Сложение простых чисел** - Сумма всех простых чисел меньше двух миллионов
- **11. Наибольшее произведение в таблице**
- **12. Треугольное число с большим количеством делителей**
- **14. Самая длинная последовательность Коллатца**
- **20. Сумма цифр факториала** - Сумма цифр в числе 100!

## 🚀 Использование

Для запуска решения конкретной задачи:

```bash
python "1. Числа, кратные 3 или 5/1.py"
```
